# 🌐 Portfólio Pessoal

Este repositório contém o código-fonte do meu portfólio pessoal, uma aplicação web desenvolvida para apresentar a minha presença profissional, competências técnicas e informações de forma clara, moderna e acessível.

---

## 📌 Sobre o Projeto

O objetivo principal deste projeto é servir como uma página de apresentação pessoal e profissional. O site foi construído com uma estrutura simples, focada em usabilidade, performance e leitura agradável.

### Destaques do Design e Funcionalidades:
- **Tema Escuro (Dark Mode):** Interface visual moderna com fundo preto absoluto (`#000000`) e destaques na cor roxa (`#8a2be2`).
- **Navegação Suave (Smooth Scroll):** Menu superior fixo que permite navegar facilmente pelas seções da página.
- **Layout Responsivo:** Organização em grade (CSS Grid) e caixas flexíveis (Flexbox) que adaptam a visualização em diferentes tamanhos de tela.
- **Elementos Interativos:** Botões e cartões com efeitos de transição ao passar o cursor (*hover*).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e acessível do conteúdo.
- **CSS3:** Estilização personalizada, animações, layout responsivo e transições visuais.
- **Font Awesome:** Biblioteca de ícones vetoriais integrada para enriquecer a interface.

---

## 📝 Resumo

Este portfólio sintetiza a minha trajetória e aprendizados no desenvolvimento web Front-End. Ele reúne uma interface limpa e intuitiva, destacando as minhas principais habilidades técnicas, experiência com tecnologias modernas do ecossistema Web/Python e atalhos rápidos para os meus principais trabalhos e projetos.
